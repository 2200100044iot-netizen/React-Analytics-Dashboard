# React Analytics Dashboard

A responsive analytics dashboard focused on data visualization, component-driven UI and client-side filtering.

## Features
- KPI cards
- Revenue line chart
- Traffic source donut chart
- Monthly bar chart
- Recent orders table
- Responsive desktop/mobile layout
- Loading-friendly component structure
- Clean dashboard navigation

## Tech Stack
React · TypeScript · Vite · Recharts · Lucide React · CSS

## Run
```bash
npm install
npm run dev
```

## Frontend concepts demonstrated
Component composition, responsive layouts, chart integration, typed props, dashboard information architecture and accessible controls.
